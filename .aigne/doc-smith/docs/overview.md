# Overview

`to-where-cli` is a command-line utility designed to simplify your workflow by using an alias mechanism to open obscure or hard-to-remember URLs. Instead of manually typing long repository links or search queries, you can create short, memorable aliases to quickly access GitHub repositories, search npm packages, and query various search engines directly from your terminal.

This tool is ideal for developers who frequently interact with services like GitHub, npm, and Google, helping to save time and reduce context switching.

## Key Features

- **Alias-based Navigation:** Create, manage, and use simple aliases for any website or URL you find hard to remember.
- **Integrated Git Workflow:** Instantly open specific pages of a Git repository, such as issues, pull requests, or the project's homepage.
- **Direct Search Commands:** Go straight to the search results on popular platforms and search engines, including:
  - npm
  - GitHub
  - Google
  - Bing
  - Baidu

## Supported Platforms

Currently, `to-where-cli` officially supports the following operating systems:

- macOS
- Windows
