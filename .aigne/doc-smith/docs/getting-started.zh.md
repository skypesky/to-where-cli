# 快速入门

欢迎使用 `to-where-cli`！这款命令行工具旨在简化您的工作流程，它允许您为冗长或复杂的 URL 创建和使用简短易记的别名。您无需费力记住 GitHub 仓库、NPM 包或搜索查询的晦涩地址，只需一个简单的别名，即可直接从终端打开它们。

本指南将引导您完成初始设置，并介绍开始有效管理别名所需的基本命令。
